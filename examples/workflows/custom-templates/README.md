# Complete custom template set

This project owns a complete template root generated by `dbmd init-templates`
and selected through `[templates].dir`. The templates preserve every required
backend and layout entrypoint even though this example renders SQLite; dbmd
never falls back to embedded files when a custom root is selected.

Requirements: `dbmd`, `just`, and `sqlite3`.

```sh
just render
just verify
```

The single-file root adds a project-owned introductory note before dispatching
to the ordinary backend entrypoint. Inspect `templates/dbmd/` to see the full
editable contract. `just down` removes the disposable database.
