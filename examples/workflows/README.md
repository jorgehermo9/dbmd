# Workflow examples

These projects focus on behavior that crosses backend boundaries:

- `multi-source-embedded/` orders SQLite and DuckDB sources in one artifact.
- `layouts/` renders the same database as a file and directory tree.
- `custom-templates/` owns a complete template set.
- `canonical-lifecycle/` demonstrates render, verify, and intentional drift.

Each project uses the common `just render`, `just verify`, and `just down`
interface described in the repository's [examples index](../README.md).
